Теорема Пифагора

a2 + b2 = c2

В прямоугольном треугольнике квадрат гипотенузы равен сумме квадратов катетов.

Три квадрата на сторонах

Меняйте катеты. Площадь розового квадрата всегда равна сумме площадей синего и жёлтого. Клетки внутри квадратов можно пересчитать.

Катеты a и b

Стороны, между которыми прямой угол.

Гипотенуза c

Сторона напротив прямого угла. Она самая длинная в треугольнике.

Обратная теорема

Если в треугольнике a2 + b2 = c2, то он прямоугольный.

Пример: стороны 5, 12, 13. Считаем 25 + 144 = 169 = 132, значит прямой угол есть.

Если квадрат большей стороны меньше суммы квадратов двух других, треугольник остроугольный. Если больше, тупоугольный.

    Формулы

    Гипотенузаc = √a2 + b2
    Катетa = √c2 − b2
    Диагональ прямоугольникаd = √a2 + b2
    Диагональ квадратаd = a√2 ≈ 1,41a
    Высота равностороннего треугольникаh = a√3 / 2 ≈ 0,87a
    Расстояние между точкамиd = √(x2 − x1)2 + (y2 − y1)2

    Как решать задачу

    1. Найдите прямой угол. Стороны рядом с ним катеты, напротив него гипотенуза.
    2. Решите, что неизвестно: гипотенуза или катет.
    3. Гипотенуза: сложите квадраты катетов. Катет: вычтите из квадрата гипотенузы квадрат другого катета.
    4. Извлеките квадратный корень.
    5. Проверьте: гипотенуза должна получиться длиннее каждого катета.

    Частые ошибки

    • Сложили стороны, а не их квадраты: 3 + 4 вместо 32 + 42.
    • Забыли извлечь корень: нашли c2 и записали его как c.
    • Нашли катет сложением вместо вычитания.
    • Применили теорему к треугольнику без прямого угла.

    Пифагоровы тройки

    Целые числа, для которых a2 + b2 = c2. Если умножить тройку на любое число, получится новая тройка.
